# طراحیِ پنل حامی (Hami Panel)

## اصلِ بنیادین

> لینکی که تولید می‌کنیم، باید **قبل از تحویل، توسط خودِ پنل تست شده باشد.**

این یک اصلِ طراحی است، نه یک ویژگی. یعنی:

- تولیدِ لینک یک تابعِ **pure** است: ورودی‌اش فقط «اینباندِِ حل‌شدهٔ همین کاربر» است،
  نه یک جستجو در کلِ پایگاه داده. ببینید: `internal/link`.
- هیچ مسیرِ «حدس بزن کدام اینباند» وجود ندارد. اگر چیزی کم باشد، تابع خطا می‌دهد،
  نه اینکه از جای دیگری پر شود.
- هر قالبِ لینک تستِ واحد دارد، و تست‌ها **شکست‌های واقعیِ پنل‌های دیگر** را بازتولید می‌کنند.

## لایه‌ها

```
cmd/hami-panel      نقطهٔ ورود: پرچم‌ها، تنظیمات، راه‌اندازیِ سرویس‌ها
internal/api        HTTP API (مدیریت، کاربران، ساب‌لینک، گره‌ها)
internal/core       مدیریتِ فرایندِ Xray/sing-box و تولیدِ کانفیگِ سرور
internal/link       تولید و اعتبارسنجیِ لینکِ کلاینت  ← pure، بدون وابستگی
internal/verify     تستِ واقعیِ کانفیگ (canary) و نگهبانِ سلامت
internal/store      پایگاه داده، مهاجرت‌ها، مدل‌ها
web/                رابطِ React (ساخته‌شده در زمانِ build، جاسازی‌شده در فایل اجرایی)
```

## مدلِ داده (نسخهٔ اولیه)

```sql
inbounds (id, remark, protocol, port, transport, security, host,
          tls_sni, reality_pbk, reality_sid, reality_sni, reality_fp,
          path, xhttp_mode, header_type, flow, enable, tag)

clients  (id, inbound_id, uuid, password, email, enable,
          total_bytes, up_bytes, down_bytes, expire_at, ip_limit, speed_limit_bps)

traffic  (client_id, ts, up_bytes, down_bytes)     -- نمونه‌برداریِ دوره‌ای

nodes    (id, name, address, api_key, last_seen, status)   -- برای چندسروره
events   (ts, level, actor, message, meta)                 -- audit log
```

## جریانِ تولیدِ یک کانفیگ

1. مدیر اینباند می‌سازد → در پایگاه داده ذخیره می‌شود
2. کاربر/کلاینت به اینباند وصل می‌شود (یک رابطهٔ صریح)
3. `core` کانفیگِ Xray را از روی همین رکورد می‌سازد و هسته را ریلود می‌کند
4. `link.Build(inbound, client)` لینک را از **همان رکورد** می‌سازد
5. `verify.Canary(link)` با خودِ لینک وصل می‌شود و رد شدنِ ترافیک را تأیید می‌کند
6. اگر مرحلهٔ ۵ شکست خورد ⇒ لینک تحویل داده نمی‌شود و مدیر هشدار می‌گیرد

## امنیت

- عدمِ استفاده از رمزِ پیش‌فرض؛ نخستین اجرا رمز را اجباری می‌کند
- توکنِ ساب‌لینک امضا‌شده (HMAC) و قابلِ ابطال
- محدودیتِ نرخ روی ورود و API؛ قفل شدن پس از تلاش‌های ناموفق
- لاگِ رویدادها برای هر عملِ مدیریتی
- هیچ مسیرِ مدیریتی بدون احراز هویت؛ عدمِ افشای مسیرِ پنل در پاسخ‌ها

## سازگاری

- خروجیِ ساب‌لینک برای v2rayN/v2rayNG، Shadowrocket، Clash، sing-box
- واردات از 3x-ui و مرزبان (مرحلهٔ ۶)
- نصب روی Ubuntu/Debian و هر سیستمِ systemd‌دار
