# طراحی صفحه ورود پنل حامی — بروزرسانی ۱۴۰۵/۰۷/۰۷

## درخواست کاربر (قطعی)
- **هیچ شباهتی به 3X-UI نباشد.** کاربر با ورود به پنل نباید حس کپی از دیگران داشته باشد.
- برندینگ: به‌جای 3X-UI از **HP-UI** یا **Hp-ui** (مخفف Hami Panel) یا هر چیز شیک‌تر استفاده شود.
- رنگ‌ها فقط پالت هستند، نه کپی چیدمان:
  - روشن: #9DC183
  - تیره: #0B6623
  - خیلی تیره: #043927

## تصمیم طراحی (پیشنهاد نهایی برای پیاده‌سازی)
- نام رسمی صفحه ورود: **HAMI PANEL** — با تگ کوچک `HP-UI` در گوشه یا به‌عنوان لوگو تایپ.
  - آلترناتیو شیک‌تر اگر کاربر بپسندد: **HAMI CORE** یا **HAMI GATE** — ولی پیش‌فرض همان **HP-UI / HAMI PANEL** می‌ماند چون مخفف واضح است و با HP (شرکت) اشتباه نمی‌شود چون همیشه با HAMI می‌آید.
- لوگو: حرف H با برگ کوچک یا نقطه سبز #00A86B (رنگ برند اتصال Scorpion) — نه لوگوی 3X-UI
- چیدمان متفاوت از 3X-UI:
  - **Split layout**: چپ برندینگ + پترن گرید سبز کم‌رنگ، راست فرم ورود (نه کارت وسط با Hello/Welcome)
  - هدر ندارد، فوتر کوچک: HAMI SMART SYSTEMS
  - ورودی‌ها با لیبل فارسی/انگلیسی: نام کاربری / Username
  - دکمه ورود با گرادیانت #0B6623 → #043927، نه آبی 3X-UI
  - سوییچ تم: سه حالت (روشن/تیره/خیلی‌تیره) با آیکون خورشید/ماه، نه دکمه‌های دایره‌ای 3X-UI
  - انیمیشن خیلی سبک، بدون grid تیره 3X-UI
- متن‌ها: نه Hello/Welcome — مثلا "ورود به پنل حامی" / "HAMI PANEL Login"
