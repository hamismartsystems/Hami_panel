# نقشهٔ راهِ پنل حامی (Hami Panel)

منطقِ ترتیب: **اول چیزی که جلوی خرابی را می‌گیرد، بعد چیزی که امکانات اضافه می‌کند.**
هر مرحله باید به‌تنهایی قابلِ استفاده و قابلِ انتشار باشد.

## مرحلهٔ ۰ — پایه (اکنون اینجا هستیم)
- [x] مخزن، مجوزِ GPL-3.0، مستندات
- [x] `internal/link`: تولیدِ لینک برای vless / vmess / trojan / shadowsocks
- [x] تستِ بازگشت برای «نشتِ تنظیمات Reality از اینباندِ دیگر»
- [x] اعتبارسنجیِ اینباندِ نیمه‌پیکربندی‌شده (خرابی باید اینجا فریاد بزند)
- [ ] مدلِ داده (اینباند، کلاینت، ترافیک، گره) + مهاجرت‌ها
- [ ] مدیریتِ فرایندِ Xray و تولیدِ کانفیگِ سازگار با لینک‌ها

**خروجی این مرحله:** یک فایل اجرایی که بتواند یک اینباندِ VLESS+Reality بسازد و
لینکی بدهد که **همان لحظه تست شده باشد**.

## مرحلهٔ ۱ — پایداری (اولویتِ اولِ کاربر)
- [ ] **کانِری‌تست:** پنل با خودِ لینک وصل می‌شود و رد شدنِ ترافیک را تأیید می‌کند
- [ ] نگهبانِ داخلی: بررسیِ پورت، TLS، صحتِ لینک؛ هشدار؛ تعمیرِ خودکار
- [ ] پین‌کردنِ نسخهٔ هسته + ارتقای مرحله‌ای با بازگشت خودکار
- [ ] بک‌آپ/بازیابیِ یک‌دستوری (پایگاه داده + تنظیمات)
- [ ] گزارشِ رویدادها (audit log)

## مرحلهٔ ۲ — کاربران و اشتراک
- [ ] کاربر، سهمیه، انقضا، بازنشانیِ دوره‌ای
- [ ] ساب‌لینکِ چندقالبه: v2ray / sing-box / Clash / Shadowrocket
- [ ] محدودیتِ تعداد دستگاه (IP limit) و محدودیتِ سرعت
- [ ] هشدار به کاربر (تلگرام/ایمیل) هنگامِ نزدیک شدن به سقف یا انقضا
- [ ] صفحهٔ وضعیتِ مشتری و QR

## مرحلهٔ ۳ — چندسروره و فِیل‌اُور
- [ ] عاملِ سبک روی هر گره + ارتباطِ امضا‌شده با پنلِ مرکزی
- [ ] سلامتِ هر گره و حذفِ خودکار از ساب‌لینک
- [ ] ساب‌لینکِ هوشمند: فقط گره‌های سالم، به ترتیبِ کیفیت
- [ ] توزیعِ کاربر روی چند گره

## مرحلهٔ ۴ — پروتکل‌های نو و ضدِ فیلترینگ
- [ ] sing-box به‌عنوان هستهٔ دوم (Hysteria2، TUIC، AnyTLS)
- [ ] قالب‌های آماده برای VLESS+Reality، XHTTP، HTTPUpgrade، gRPC
- [ ] بررسیِ خودکارِ سلامتِ مقصدِ Reality (dest/SNI) و اثرانگشتِ uTLS
- [ ] چرخشِ ShortID و کلید

## مرحلهٔ ۵ — فروش و خودکارسازی
- [ ] بات تلگرام (ساخت کاربر، تمدید، وضعیت)
- [ ] اتصال به درگاه/کیف پول و تمدیدِ خودکار
- [ ] نقشِ فروشنده (reseller) و سهمیه برای هر فروشنده
- [ ] گزارش‌های مالی و مصرف

## مرحلهٔ ۶ — مهاجرت و پذیرشِ عمومی
- [ ] واردات از 3x-ui (پایگاه دادهٔ SQLite) و مرزبان
- [ ] خروجیِ استاندارد برای ابزارهای رایج
- [ ] مستنداتِ کامل به انگلیسی و فارسی
- [ ] بستهٔ نصب (deb / rpm / docker) و اسکریپتِ یک‌خطی
