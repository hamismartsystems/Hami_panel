Forgot password — how it works

HP-UI does not send password via email by default. Admin password is stored hashed on the server. If you forgot it, reset from server console.

If SMTP is configured in /opt/hami-panel/config.yaml, you can enable email reset. Otherwise use console:

ssh root@your-server hami admin list hami admin reset --user admin --new-password 'YOUR_NEW_PASS' # or generate random: hami admin reset --user admin --random systemctl restart hami-panel

For Docker: docker exec -it hami-panel hami admin reset --user admin

After reset, login with new password. This modal is client-side only — no request is sent until you configure SMTP.
